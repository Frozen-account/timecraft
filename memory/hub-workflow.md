# Как работает хаб

- **Источник правды — файлы в Git:** `backlog/tasks.json`, `content/calendar.json`, `projects/*.md`, `memory/*.md`, `agents/access.json`. Сборка проверяет их и падает с указанием файла и номера записи.
- **Статусы задач:** `backlog`, `in_progress`, `review`, `done`. Статуса `todo` нет — используем `backlog`.
- **Исполнители:** `Claude`, `Gemini`, `Human`. Если исполнитель не указан — `Human`.
- **Описание задачи** хранится в поле `notes` (не `description`).
- **Календарь (`/schedule`):** переносы и новые задачи сохраняются только в браузере. Чтобы зафиксировать: «Скопировать JSON» → вставить в `backlog/tasks.json` → коммит → после деплоя нажать «Сбросить», иначе новые задачи задублируются.
- **Доска `/tasks`** только читает `tasks.json`; новые задачи из календаря появляются там после коммита.

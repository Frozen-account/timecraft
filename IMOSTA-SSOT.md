# 🏛️ IMOSTA Digital Marketing — Single Source of Truth (SSOT)

> **Версия:** 1.0 (Октябрь 2026)  
> **Назначение:** Единая база знаний, брендбук, продуктовая логика и контекст для AI-ассистентов (Claude Code, Gemini) и команды разработки.

---

## 1. Бренд и позиционирование
* **Бренд:** IMOSTA Group (imosta.pl / jdg.imosta.pl)
* **Профиль:** Комплексный бухгалтерский, кадровый и юридический консалтинг для малого и среднего бизнеса в Польше.
* **Партнерская экосистема:** OPRIMO BPO (аутсорсинг бизнес-процессов, oprimo.pl).
* **Ключевой эксперт:** Татьяна Бакаева (Главный бухгалтер / Head of Accounting). Экспертиза: Estoński CIT, безопасность правления (KSH), KSeF, JPK_CIT, налоговый аудит.
* **Тональность (Tone of Voice):** Профессиональный, авторитетный, прозрачный, практичный («без заумной воды, на понятном предпринимателю языке»).

---

## 2. Дизайн-система и UI/UX стандарты
* **Стек фронтенда:** React, Vite, TypeScript, Tailwind CSS.
* **Типографика:**
  * Семейство: `Montserrat` (Google Fonts).
  * Начертания: `400` (Body), `500` (Medium), `600` (Semi-bold), `700` (Headings/CTA), `800` (Hero titles).
  * Поддержка языков: PL, RU, EN.
* **Цветовая палитра (Brand Palette):**
  * `Primary Accent (Brand Red):` `#D11329` (Кнопки CTA, важные бейджи, ховеры, акценты).
  * `Dark/Black:` `#151515`, `#000000` (Заголовки, темные контрастные секции, футер).
  * `Neutral Gray (Text):` `#5F5F5F`, `#4B5563` (Основной текст, подзаголовки).
  * `Background Lights:` `#FFFFFF`, `#F8F9FA`, `#F3F4F6` (Чередование секций).
* **Компоненты:**
  * Скругления: `rounded-lg` (8px) для инпутов/кнопок, `rounded-xl` (12-16px) для карточек.
  * Тени: мягкие `shadow-sm`, при ховере `shadow-md` с переходом `transition-all duration-200`.

## 3. Продуктовые воронки и сегменты аудитории

### Сегмент A: JDG (Jednoosobowa Działalność Gospodarcza)
* **Целевая аудитория:** IT-специалисты (B2B-контракты), маркетологи, самозанятые эксперты, стартапы.
* **Ключевые боли:**
  * Сложность выбора между Ryczałt, Skala podatkowa и Podatek liniowy.
  * Как не потерять льготы ZUS (Ulga na start, Mały ZUS Plus).
  * Языковой барьер с Urząd Skarbowy / ZUS.
* **Оффер:** «Быстрый старт JDG за 24 часа + выбор минимального налога с персональным бухгалтером».
* **Ключевые фичи на лендинге:**
  * Интерактивный калькулятор налога (сравнение ставок 8.5%, 12%, 19%).
  * Лид-магнит / Квиз: «Какая форма налогообложения выгоднее для твоего дохода».

### Сегмент B: Spółka z o.o. (ООО в Польше)
* **Целевая аудитория:** Действующий бизнес, торговля, логистика, B2B-компании, несколько соучредителей.
* **Ключевые боли:**
  * Ответственность правления (Zarząd, art. 299 KSH).
  * Полная бухгалтерия (Pełna księgowość) и сдача Sprawozdanie Finansowe в KRS.
  * Как легально выводить чистую прибыль с минимальным налогом (Powołanie, Estoński CIT 0%, дивиденды).
* **Оффер:** «Комплексная бухгалтерия Sp. z o.o. с финансовой гарантией и защитой интересов правления».
* **Ключевые фичи на лендинге:**
  * Блок сравнения Estoński CIT vs Классический CIT.
  * Чек-лист безопасности для Zarząd.

## 4. Архитектура лидогенерации и Backend
* **Прием заявок:** Серверная обработка POST-запросов (Next.js API route / Supabase Edge Functions / FastAPI).
* **Уведомления:** Мгновенный пуш в Telegram-чат отдела продаж/координатора.
* **Обязательные поля лида:**
  * Имя / Телефон / Email / Telegram ник.
  * Тип деятельности (`JDG` / `Spolka` / `Консультация`).
  * Предполагаемый оборот или стадия бизнеса.
  * Полные UTM-метки (`utm_source`, `utm_medium`, `utm_campaign`, `utm_content`).
